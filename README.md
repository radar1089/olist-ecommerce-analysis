# 📊 Olist E-Commerce Business Analysis

An end-to-end Data Analytics project using the Olist Brazilian E-Commerce dataset. This project aims to analyze business performance, identify revenue trends, understand customer behavior, evaluate seller performance, and investigate the root cause of the revenue decline in June 2017.

---

## 📌 Project Overview

This project covers the complete data analytics workflow:

- Data Cleaning
- Data Profiling
- Exploratory Data Analysis (EDA)
- Business Analysis
- Dashboard Development in Power BI
- Business Recommendations
